# Бархат — концепт сайта частного кондитера

Демонстрационная работа для портфолио: сайт-визитка с каталогом начинок, галереей и пошаговым конструктором заказа.

- `index.html` — сайт
- `builder.html` — конструктор заказа (кликабельный прототип, заявка никуда не отправляется)
- `mockup.html` — доска макета: экраны для компьютера и телефона, пояснения к анимациям

Данные, цены и фотографии (Unsplash) демонстрационные.
